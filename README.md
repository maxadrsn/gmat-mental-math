# GMAT Mental Math

Daily mental-math drills for GMAT Quant: 19 topics, 3 difficulty levels, mistake analytics and a daily streak.
Static site (no build step), installable as a PWA. Progress is stored in the browser (localStorage); use Progress → Backup to export/import.

Deploy: push to `main`, Vercel redeploys automatically. Bump `VERSION` in `sw.js` on every change.
